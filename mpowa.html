Welcome to MPowa, where agents meet compliance. AI for humanity.

Select a governance module, ask a question, and MPowa's agents verify the answer against that module's rulebook before you act on it.

Governance modules

Each module encodes one regulatory rulebook. Selecting a module scopes every agent check that follows to its rules — pricing is per module, billed monthly.

Check your AI and be insured for your agent actions. Insurance guaranteed when Anchor Ledger compliant.

Agent checks

Every question runs through the same five-step pipeline before you see an answer — nothing reaches you unverified.

Pipeline status Standing by — select a module and ask a question
  1. Regulatory Scan Checks the query against the selected module's rulebook Idle
  2. Bias & Fairness Screens the draft answer for skewed or unfair framing Idle
  3. Data Provenance Confirms every citation traces to a verifiable source Idle
  4. Audit Trail Writes an immutable record of the check for later review Idle
  5. Compliance Verdict Issues a pass / hold / fail decision with reasoning Idle

Engage our service through API and be compliant automatically

Call the same governance modules and agent-check pipeline directly from your own systems. Every request runs the full pipeline and is logged automatically — nothing to configure by hand.

Example request Illustrative — does not call a live endpoint 
curl -X POST https://api.mpowa.example/v1/checks \
  -H "Authorization: Bearer $MPOWA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "module": "gold-law",
    "query": "Can we hold client bullion under Gold Law custody rules?"
  }'

> {
>   "verdict": "passed",
>   "checks": ["regulatory", "bias", "provenance", "audit", "verdict"],
>   "ledger_url": "https://ledger.mpowa.example/tx/0x4f2a7c119e31"
> }
  • Same governance modules and agent checks as the interface above
  • Every call logged to the compliance ledger automatically, no manual step
  • Returns a pass / hold / fail verdict with reasoning in the response
